# Actividad 1 - Conceptos Básicos de POO (10%)

## Descripción

Actividad 1 del curso de Programación Orientada a Objetos.
Basada en los ejercicios del libro de Leonardo Bermón Angarita.

## Ejercicios

1. **Ejercicio Resuelto No 4** - Edades de la familia de Juan
   - Archivo: `Ejercicio4_EdadesJuan.java`
   - Concepto: Definición de clases

2. **Ejercicio Resuelto No 5** - Prueba de escritorio
   - Archivo: `Ejercicio5_PruebaEscritorio.java`
   - Concepto: Métodos privados y cálculos

3. **Ejercicio Propuesto No 12** - Cálculo de salario
   - Archivo: `Ejercicio12_SalarioEmpleado.java`
   - Concepto: Constructores sobrecargados

4. **Ejercicio Propuesto No 14** - Cuadrado y cubo
   - Archivo: `Ejercicio14_CuadradoCubo.java`
   - Concepto: Métodos con retorno

5. **Ejercicio Propuesto No 17** - Círculo
   - Archivo: `Ejercicio17_Circulo.java`
   - Concepto: Constantes estáticas

## Compilación

```bash
cd Actividad_1/src
javac *.java
```

## Ejecución

```bash
java Ejercicio4_EdadesJuan
java Ejercicio5_PruebaEscritorio
java Ejercicio12_SalarioEmpleado
java Ejercicio14_CuadradoCubo
java Ejercicio17_Circulo
```
