## Descripción del Curso

Este repositorio contiene las actividades prácticas del curso de Programación 
Orientada a Objetos 2026-2S. Cada actividad aborda conceptos específicos de POO 
usando Java como lenguaje de programación, basándose en el libro "Ejercicios de 
programación orientada a objetos con Java y UML" de Leonardo Bermón Angarita.

## Actividades

- **Actividad 1** (10%): Conceptos básicos de POO
  - Definición de clases, atributos y métodos
  - Constructores y encapsulación
  - Getters y setters

- **Actividad 2** (20%): POO intermedia
  - Definición de atributos con tipos primitivos
  - Métodos con y sin valores de retorno
  - Métodos con parámetros
  - Figuras geométricas y operaciones bancarias
